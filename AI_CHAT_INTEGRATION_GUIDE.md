# Интеграция AI API в чат

## Описание
Интеграция AI API для обработки сообщений в чате с таймаутом 10 секунд и fallback на моковые ответы.

## API Endpoint
```
GET https://8f95fc22e4f6.ngrok-free.app/ollama_get?advisor=prompt
```

## Компоненты

### 1. AIApi (`src/utils/aiApi.ts`)
- HTTP клиент для работы с AI API
- Таймаут 10 секунд
- Fallback на моковые ответы при ошибках
- Проверка доступности API

### 2. ChatStore (`src/stores/ChatStore.ts`)
- MobX store для управления состоянием чата
- Интеграция с AIApi
- Обработка сообщений пользователя и AI
- Состояния загрузки и ошибок

### 3. Обновленный ChatScreen
- Интеграция с ChatStore
- Индикатор загрузки
- Отображение источника ответа (AI/Mock)
- Обработка ошибок

## Логика работы

### 1. Отправка сообщения пользователя:
```typescript
// Пользователь отправляет сообщение
chatStore.addUserMessage("Привет, Тоша!");

// ChatStore автоматически:
// 1. Добавляет сообщение пользователя
// 2. Показывает индикатор загрузки
// 3. Отправляет запрос в AI API
// 4. Получает ответ или использует мок
// 5. Добавляет ответ AI
// 6. Скрывает индикатор загрузки
```

### 2. AI API запрос:
```typescript
// GET https://8f95fc22e4f6.ngrok-free.app/ollama_get?advisor=prompt
// Пример: https://8f95fc22e4f6.ngrok-free.app/ollama_get?advisor=Привет%20Тоша
```

### 3. Обработка ответа:
```typescript
// Успешный ответ от AI
{
  answer: "Привет! Рад тебя видеть!",
  status: "success",
  source: "ai"
}

// Fallback на мок при ошибке/таймауте
{
  answer: "Привет! Я твой виртуальный друг Тоша...",
  status: "success", 
  source: "mock"
}
```

## Таймаут и Fallback

### ⏱️ Таймаут 10 секунд:
- Если AI API не отвечает в течение 10 секунд
- Автоматический переход на моковые ответы
- Пользователь не ждет бесконечно

## Тестирование

### Проверка AI API:
```typescript
// Проверка доступности
const isHealthy = await aiApi.checkHealth();
console.log('AI API доступен:', isHealthy);
```

### Тестовые сценарии:
1. **Нормальная работа** - AI отвечает быстро
2. **Таймаут** - AI не отвечает 10+ секунд
3. **Ошибка сети** - Нет подключения к интернету
4. **Ошибка сервера** - AI API возвращает 500

### Ожидаемые результаты:
- ✅ Быстрый ответ от AI
- ✅ Fallback на мок при таймауте
- ✅ Fallback на мок при ошибке
- ✅ Индикатор загрузки работает
- ✅ Источник ответа отображается
