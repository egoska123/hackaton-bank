# WebSocket система уведомлений для KidBank

## Описание

Реализована система WebSocket уведомлений для получения советов от ИИ в реальном времени. При получении совета появляется анимированная плашка, при нажатии на которую пользователь переходит в чат с полным текстом совета.

## Компоненты

### 1. WebSocketService (`src/utils/websocketService.ts`)
- Управляет WebSocket соединением с сервером
- Обрабатывает события `connected`, `new_advice`, `pong`
- Поддерживает JWT аутентификацию

### 2. AdviceStore (`src/stores/AdviceStore.ts`)
- MobX store для управления состоянием уведомлений
- Автоматически подключается к WebSocket при инициализации
- Управляет отображением уведомлений

### 3. AdviceNotification (`src/components/AdviceNotification/`)
- Анимированный компонент уведомления
- Автоматическое скрытие через 5 секунд
- При нажатии переходит в чат

### 4. Обновленный Navigator
- Интеграция с AdviceStore
- Управление отображением уведомлений
- Передача советов в ChatScreen

### 5. Обновленный ChatScreen
- Поддержка начальных советов
- Отображение советов в чате

## Запуск тестового сервера

1. Установите зависимости:
```bash
npm install express socket.io jsonwebtoken
```

2. Запустите сервер:
```bash
node test-websocket-server.js
```

Сервер будет доступен на `http://localhost:3000`

## API Endpoints

### POST /websocket/send-test-advice
Отправить тестовый совет:
```bash
curl -X POST http://localhost:3000/websocket/send-test-advice \
  -H "Content-Type: application/json" \
  -d '{"advice": "Тестовый совет от ИИ!"}'
```

### GET /websocket/connected-users
Получить список подключенных пользователей:
```bash
curl http://localhost:3000/websocket/connected-users
```

## Структура данных

### AdviceData
```typescript
{
  advice: string;           // Текст совета
  timestamp: string;        // Время получения
  operation?: 'transaction' | 'history' | 'default'; // Тип операции
}
```

## События WebSocket

### Клиент → Сервер
- `ping` - проверка соединения

### Сервер → Клиент
- `connected` - подтверждение подключения
- `new_advice` - новый совет от ИИ
- `pong` - ответ на ping

## Автоматические уведомления

Сервер автоматически отправляет советы:
- Через 5 секунд после подключения (тестовый совет)
- Каждые 30 секунд (случайные советы)
- При вызове API `/websocket/send-test-advice`

## Тестирование

1. Запустите тестовый сервер
2. Запустите приложение KidBank
3. Дождитесь появления уведомления (5 секунд)
4. Нажмите на уведомление для перехода в чат
5. Используйте API для отправки дополнительных советов

## Примеры советов

Сервер отправляет различные типы советов:
- **transaction**: советы по транзакциям и тратам
- **history**: советы по анализу истории
- **default**: общие финансовые советы
