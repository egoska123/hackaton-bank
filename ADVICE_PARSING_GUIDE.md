# Обновление парсинга советов

## Описание
Обновлена логика обработки советов в WebSocket для правильного парсинга JSON ответов и извлечения поля `answer`.

## Проблема
При получении советов через WebSocket приходили данные в разных форматах:

### 1. JSON с полем answer:
```json
{
  "agent": "piggy",
  "answer": "Молодец! У тебя уже 255 рублей в копилке на велосипед, ты стал на -5 рублей ближе к своей цели в 500 рублей! Продолжай в том же духе, и скоро у тебя будет новый велосипед!",
  "status": "позитивный"
}
```

### 2. Простой текст:
```
Простой совет без JSON
```

## Решение

### Обновленный AdviceStore
Добавлена функция `parseAdviceText()` в `src/stores/AdviceStore.ts`:

```typescript
/**
 * Парсит текст совета, извлекая поле answer из JSON или возвращая текст как есть
 */
private parseAdviceText(adviceText: string): string {
  try {
    // Пытаемся распарсить как JSON
    const parsed = JSON.parse(adviceText);
    
    // Если есть поле answer, возвращаем его
    if (parsed.answer) {
      return parsed.answer;
    }
    
    // Если нет поля answer, возвращаем весь объект как строку
    return JSON.stringify(parsed);
  } catch (error) {
    // Если не удалось распарсить JSON, возвращаем текст как есть
    return adviceText;
  }
}
```

### Обновленный setCurrentAdvice
```typescript
setCurrentAdvice(advice: AdviceData | null) {
  if (advice) {
    // Парсим совет для извлечения поля answer из JSON
    const parsedAdvice = this.parseAdviceText(advice.advice);
    this.currentAdvice = {
      ...advice,
      advice: parsedAdvice
    };
  } else {
    this.currentAdvice = null;
  }
}
```

## Логика работы

### 1. JSON с полем answer:
**Входные данные:**
```json
{"agent":"piggy","answer":"Молодец! У тебя уже 255 рублей в копилке на велосипед, ты стал на -5 рублей ближе к своей цели в 500 рублей! Продолжай в том же духе, и скоро у тебя будет новый велосипед!","status":"позитивный"}
```

**Результат:**
```
Молодец! У тебя уже 255 рублей в копилке на велосипед, ты стал на -5 рублей ближе к своей цели в 500 рублей! Продолжай в том же духе, и скоро у тебя будет новый велосипед!
```

### 2. Простой текст:
**Входные данные:**
```
Простой совет без JSON
```

**Результат:**
```
Простой совет без JSON
```

### 3. JSON без поля answer:
**Входные данные:**
```json
{"agent":"piggy","status":"позитивный","message":"Тестовое сообщение"}
```

**Результат:**
```json
{"agent":"piggy","status":"позитивный","message":"Тестовое сообщение"}
```

### 4. Некорректный JSON:
**Входные данные:**
```
{"agent":"piggy","answer":"Тест",}
```

**Результат:**
```
{"agent":"piggy","answer":"Тест",}
```

## Интеграция

### WebSocket обработка
```typescript
websocketService.on('new_advice', (advice: AdviceData) => {
  this.setCurrentAdvice(advice); // Автоматически парсится
  this.showNotification = true;
  console.log('New advice received:', advice);
});
```

### AdviceNotification
Компонент уже правильно обрезает текст для уведомления:

const truncatedText = advice.advice.length > 80

## Преимущества

### ✅ Универсальность
- Поддерживает оба формата данных
- Автоматически определяет тип входящих данных

### ✅ Надежность
- Graceful fallback при ошибках парсинга
- Не ломает существующую функциональность

### ✅ Производительность
- Минимальные накладные расходы
- Парсинг только при необходимости

### ✅ Читаемость
- Пользователь видит только нужную информацию
- Убирает технические детали JSON
