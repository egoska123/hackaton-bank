# Обновление парсинга советов

## Описание
Обновлена логика обработки советов в WebSocket для правильного извлечения текста из JSON ответов.

## Проблема
При получении советов через WebSocket приходили данные в разных форматах:

### 1. JSON с полем answer:
```json
{
  "advice": "{\"agent\":\"piggy\",\"answer\":\"Молодец! У тебя уже 255 рублей в копилке на велосипед, ты стал на -5 рублей ближе к своей цели в 500 рублей! Продолжай в том же духе, и скоро у тебя будет новый велосипед!\",\"status\":\"позитивный\"}",
  "timestamp": "2025-07-31T05:31:58.445Z"
}
```

### 2. Простой текст:
```json
{
  "advice": "Простой совет от Тоши",
  "timestamp": "2025-07-31T05:31:58.445Z"
}
```

## Решение

### Обновленный AdviceStore
Добавлен метод `parseAdviceText()` в `src/stores/AdviceStore.ts`:

```typescript
/**
 * Парсит текст совета, извлекая поле answer из JSON или возвращая текст как есть
 */
private parseAdviceText(adviceText: string): string {
  try {
    // Пытаемся распарсить как JSON
    const parsed = JSON.parse(adviceText);
    
    // Если есть поле answer, возвращаем его
    if (parsed.answer) {
      return parsed.answer;
    }
    
    // Если нет answer, но есть другие поля, возвращаем весь объект как строку
    return JSON.stringify(parsed);
  } catch (error) {
    // Если не удалось распарсить JSON, возвращаем текст как есть
    return adviceText;
  }
}
```

### Обновленный setCurrentAdvice
```typescript
setCurrentAdvice(advice: AdviceData | null) {
  if (advice) {
    // Парсим совет для извлечения текста
    const parsedAdvice = this.parseAdviceText(advice.advice);
    this.currentAdvice = {
      ...advice,
      advice: parsedAdvice
    };
  } else {
    this.currentAdvice = null;
  }
}
```

## Логика работы

### 🔄 Алгоритм парсинга:
1. **Попытка JSON парсинга** - пытаемся распарсить строку как JSON
2. **Проверка поля answer** - если есть поле `answer`, извлекаем его
3. **Fallback для JSON** - если нет `answer`, но это JSON, возвращаем весь объект
4. **Fallback для текста** - если не JSON, возвращаем исходный текст

### 📝 Примеры обработки:

#### JSON с answer:
```javascript
// Входные данные
"{\"agent\":\"piggy\",\"answer\":\"Молодец! У тебя уже 255 рублей...\",\"status\":\"позитивный\"}"

// Результат
"Молодец! У тебя уже 255 рублей в копилке на велосипед, ты стал на -5 рублей ближе к своей цели в 500 рублей! Продолжай в том же духе, и скоро у тебя будет новый велосипед!"
```

#### Простой текст:
```javascript
// Входные данные
"Простой совет от Тоши"

// Результат
"Простой совет от Тоши"
```

#### JSON без answer:
```javascript
// Входные данные
"{\"agent\":\"piggy\",\"status\":\"позитивный\"}"

// Результат
"{\"agent\":\"piggy\",\"status\":\"позитивный\"}"
```

## Тестирование

### Тестовые случаи:
1. **JSON с answer** ✅ - извлекается поле answer
2. **Простой текст** ✅ - возвращается как есть
3. **JSON без answer** ✅ - возвращается весь JSON
4. **Пустая строка** ✅ - возвращается пустая строка
